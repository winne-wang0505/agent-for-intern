# 沪深 A 股决策研究 Agent

轻量、可审计的 Python 研究助手：评估每位用户风险约束，从公开市场股票池选出最多5只研究候选，输出持有周期政策、仓位与金额上限，支持可选大模型解释。不接入券商下单。

## 开始使用

需要 Python 3.11+，无需安装第三方依赖。在项目根目录运行：

```bash
# 先验证合成行情与演示用户，不能用于真实交易
python -m stock_agent --demo --llm
# 交互填写你自己的风险问卷，建议保存到仓库外
python -m stock_agent --init-profile ../private-stock-user.json
# 依据真实用户资料，扫描供应商报告的沪深A股股票池
python -m stock_agent --profile ../private-stock-user.json
# 有限监控：每轮完成后等待60秒，共10轮；Ctrl+C停止
python -m stock_agent --profile ../private-stock-user.json --watch 60 --cycles 10
# 可选：仅观察指定代码（此接口缺少自动选股需要的行业与成交额）
python -m stock_agent --profile ../private-stock-user.json --symbols sh600519 sz000001
```

交互问卷独占创建权限为0600的文件，不覆盖已有资料。无资料时默认使用空白模板 `examples/profile.json`，返回 `needs_assessment`，不会把示例资产当成用户资金。`examples/demo-profile.json` 仅供演示。真实配置、报告和密钥不要提交到公开仓库。

每轮在 `reports/latest.json` 原子替换结果；可用 `--output PATH` 指定位置。主要字段：

- `status`：`needs_assessment` 缺资料、`observation_only` 只观察、`assessed` 评估完成、`blocked` 本轮失败。评估完成不表示一定选出股票。
- `selected`：最终研究候选，不足5只不凑数；含理由、时间、金额上限和持有周期。
- `stocks`：全部行情观察记录，并非都可投资。
- `risk.personalization`：本用户约束与政策假设。
- `selection`：扫描覆盖和候选数量。
- `model`：可选模型状态及解释。

行情或用户资料失败时清空旧候选，写入 `blocked` 并以非零状态退出。监控不会在错误后继续发布旧建议，也不会自行启动后台进程。

## 风险评估

基础问卷四个维度为0–4整数：

| 字段 | 0 | 1 | 2 | 3 | 4 |
|---|---|---|---|---|---|
| experience | 无经验 | 初学 | 了解股票 | 熟悉风险 | 多年经验 |
| loss_tolerance | 不接受本金损失 | 小幅损失 | 中等损失 | 较大损失 | 很大损失 |
| horizon | 一个月内用款 | 三个月内 | 一年内 | 三年内 | 三年以上 |
| financial_capacity | 无可承受损失闲钱 | 负担重 | 有储备 | 储备充分 | 不影响生活 |

均分同时受损失意愿和财务承受能力约束。基础单股上限：保守3%、稳健5%、进取8%；基础总股票上限：15%、35%、60%。保守用户首版只观察。

`personalization` 中的事实需要本人提供，模型不能代填：

| 字段 | 含义 |
|---|---|
| capital | 可投资资金，人民币元，不含应急生活资金 |
| max_loss_pct | 可接受亏损占上述资金的百分比，0–100 |
| single_stock_cap_pct | 用户单股仓位硬上限百分比，0–100 |
| cash_needed_days | 距离最早可能取出资金的自然日数 |
| experience | 投资经验0–4，周期判断与基础问卷取较低值 |
| emergency_fund_months | 额外应急储备覆盖生活的月数 |
| excluded_types | 不买行业：bank / real_estate / alcohol；空数组为无额外排除 |
| allowed_boards | 已开通且允许板块：main / chinext / star；空数组为不参与 |

仅支持上述结构化排除类型；其他限制需要扩展分类，不能静默忽略。ST/退市名称标记始终排除，但没有完整官方风险名单。

只观察的条件：180天内可能用款、基础期限评分低于2、应急储备不足6个月、零亏损预算、零单股上限、无允许板块或保守风险级别。其他用户的组合上限取基础上限、亏损预算除以50%压力损失率、5倍单股上限中的最小值。实际损失可能超过压力假设，不能保证亏损不超预算。

持有周期是待回测的政策建议：稳健60–120自然日；经验充足的进取用户20–60自然日；每7天复核。并非到期必卖，短期资金需求不会通过缩短持有期被认定为安全。以上是简化自评和示例风险政策，没有适当性测评或收益有效性验证。

## 行情、筛选与自检

默认适配器：东方财富公开沪深A股列表 `push2.eastmoney.com`，分页扫描，核验总数、重复代码与页数上限。缺失价格、成交额或行业的数据不参与筛选。股票池仅以供应商报告为准，尚未与交易所证券名单交叉核验；分页不是同一瞬间的快照。

筛选规则：

1. 支持的沪深A股、允许板块、无ST/退市名称标记，排除用户禁止行业。
2. 行情不超过180秒且不超前5秒；仅工作日9:30–11:30和13:00–15:00生成候选。尚无完整节假日日历，节假日依赖行情过期拦截。
3. 日涨幅大于0且小于3%，绝对涨跌幅达5%排除；这是启发式信号，不是预测模型。
4. 当日成交额至少1亿元，按成交额降序，最多5只，同一行业最多2只。
5. 每个候选上限取单股上限与组合上限/5的较小值；不足5只时保留未分配预算。金额须满足最小买入单位及0.2%费用预留，否则排除。科创板按200股、其他按100股初步核验，实际以券商规则为准。

只读观察适配器：腾讯 `qt.gtimg.cn`，包含价格与行情时间；不含本版本自动选股所需行业和成交额。公开接口可能延迟、变更或不可用，不是交易所授权实时行情。

当前未读取已有持仓，不能计算实际可用资金、累计仓位和现有行业暴露。金额是新组合研究上限，不是订单数量。没有历史回测、基本面筛选、完整停牌/涨跌停检查或收益保证。

## 可选模型

在环境设置中安全配置以下变量，不要把密钥发到聊天或写入Git：

- `LLM_BASE_URL`：供应商OpenAI兼容Chat Completions的HTTPS基地址；按官方文档选择是否包含/v1。
- `LLM_MODEL`：账户可用模型名。
- `LLM_API_KEY`：密钥。

加 `--llm` 开启。模型只收到候选摘要及风险级别，不发送原始资金、问卷或全市场明细；摘要仍属于用户研究数据，需了解服务商数据政策。模型只解释，不能更改结构化风险结果或触发交易。未配置返回 `not_configured`，失败返回 `failed`，规则报告继续保留。HTTP失败包含安全的状态码与处理提示：402为余额/计费问题、401为鉴权问题、429为频率/限额问题。请求输出上限为600 token；不自动重试模型请求。禁用HTTP重定向以避免将密钥转发到其他地址。
